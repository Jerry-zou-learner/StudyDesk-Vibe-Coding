# Security and privacy

StudyDesk visualizes structured output produced by an upstream AI information workflow. The reference adapter reads and writes local Markdown, so the visualization layer itself needs neither source-system credentials nor network access.

Please do not include personal schedules, email content, private links, access tokens, or absolute home-directory paths in bug reports. Reproduce issues with the fictional fixtures in `examples/`.

For a vulnerability report, open a GitHub security advisory instead of a public issue when possible.
